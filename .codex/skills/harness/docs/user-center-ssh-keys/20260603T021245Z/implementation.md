# Implementation

## Files changed

- `packages/frontend/src/components/layout/app-layout.tsx`
  - Removed the inline password-only dialog and its mutation state.
  - Changed the sidebar user action from `修改密码` to a `/profile` `用户中心` link.
  - Added active styling for the profile link.

- `packages/frontend/src/pages/profile-page.tsx`
  - Added a dedicated user center page.
  - Added a current-password verified password update form using `PATCH /users/:id`.
  - Added SSH public key listing via `GET /users/:id/ssh-keys`.
  - Added SSH public key creation via `POST /users/:id/ssh-keys`.
  - Added delete confirmation and deletion via `DELETE /users/:id/ssh-keys/:keyId`.
  - Added copy explaining that keys are used for container SSH login.
  - Adjusted add-key form so the public key text field appears first and each field occupies its own row.
  - Added automatic key naming from the OpenSSH public key comment, with generated fallback names when no comment is present.

- `packages/frontend/src/routes/profile.tsx`
  - Added TanStack file route for `/profile`.

- `packages/frontend/src/routeTree.gen.ts`
  - Regenerated by TanStack Router tooling after adding `/profile`.

- `packages/frontend/e2e/management-routes.spec.ts`
  - Added SSH key fixture data.
  - Mocked `/users/user-admin/ssh-keys`.
  - Added visual coverage for `/profile`.
  - Added behavior coverage for SSH key name inference and generated fallback names.

- `packages/frontend/e2e/ROUTES.md`
  - Registered `/profile` visual coverage.

- `packages/frontend/e2e/__screenshots__/chromium/**`
  - Added `management-routes.spec.ts/profile-user-center.png`.

## Acceptance criteria mapping

- Sidebar action reads `用户中心`, not `修改密码`: `app-layout.tsx`.
- Clicking `用户中心` navigates to `/profile`: `app-layout.tsx`, `routes/profile.tsx`.
- `/profile` renders password change controls: `profile-page.tsx`.
- `/profile` lists SSH public keys: `profile-page.tsx`, visual fixture.
- Add/delete SSH public keys call existing backend endpoints: `profile-page.tsx`.
- Add-key form layout and automatic naming match the latest user feedback: `profile-page.tsx`.
- Copy states keys are used for container SSH login: `profile-page.tsx`.
- Visual coverage captures `/profile`: `management-routes.spec.ts`, `profile-user-center.png`.
- No generated artifacts under `packages/common/src/**`: verified during test/check.

## Risks / notes

- Backend OpenSSH key format validation remains unchanged by design.
- Existing lint warnings are unrelated and pre-existing; no new lint errors were introduced.
