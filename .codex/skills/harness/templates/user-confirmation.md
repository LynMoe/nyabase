# User Decision Guidance

Ask only for:

- material ambiguity;
- destructive, irreversible, external-costly, or credentialed actions;
- materially different product/design choices;
- subjective visual/design direction;
- explicit user approval requests.

If the user said not to ask, proceed unless one of these triggers applies.
Subagent requests for review are advisory; the lead decides whether a real user
decision trigger exists.
